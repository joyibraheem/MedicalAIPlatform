# Quick Start Guide - Medical AI Platform

## Prerequisites
- Docker Desktop installed and running

## Run the Application (2 Commands)

```bash
# 1. Navigate to the project directory
cd MedicalAIPlatform

# 2. Start everything
docker-compose up --build
```

**That's it!** Open your browser and go to: **http://localhost:8080**

## Login Credentials

- **Admin:** `admin@medicalai.com` / `Admin@123`
- **Doctor:** `doctor@medicalai.com` / `Doctor@123`

## Stop the Application

Press `Ctrl+C` in the terminal, then run:
```bash
docker-compose down
```
